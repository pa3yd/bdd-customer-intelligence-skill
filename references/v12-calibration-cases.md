# V1.2.0 边界回归用例（仅规则检查，不改历史报告）

用途：新报告出卡前，用下表检查判定链。历史档案只提供触发场景，表中「预期」是 V1.2.0 对**相同证据条件**的落点，不声称历史结论已被重新调查或改写。每例须用当次来源重新核主体、日期与事实。

| # | 场景 | 输入证据 | 预期检查 |
|---|---|---|---|
| C1 | Partner 订单活跃（集团级订单 / 通用水处理合同） | 集团订单簿、通用水处理合同；无相关外部技术采购或未覆盖工艺位 | 订单只作业务活动；仅凭这些材料 `Demand Status = Unknown`。若另有目标主体的相关采购文件，再独立定级。 |
| C2 | 母公司许可、子公司背调（主体层级） | 技术许可文件仅点名母公司；子公司官网有一般业务介绍 | 母公司许可记 `Group-level context`；子公司 Gate 不能据此判 `Confirmed`，A～F 不重复计数；查子公司执行 / 授权 / 采购链。 |
| C3 | 化学品分销主体 | 化学品目录、代工 / 贴牌、商品货源组织；无设备 / 技术代理证据 | 可确认分销能力；Partner Gate 为 `Unverified`，不可写 BDD 设备渠道已开放。仅有目录时 `Demand Status = Unknown`。 |
| C4 | 直接竞争且未检索采购切面 | 自有同工位商业产品；外部电极 / 反应器采购未检索 | 标 `Direct competitor`；`Sales Conclusion = 建议先验证`，下一步定向查非竞争切面；不得宣称机会为零。 |
| C5 | 直接竞争且已查无正面切面 | 自有同工位商业产品，定向检索后未取得外部核心部件 / 授权证据 | 第 1b 步 `暂不优先`；解释当前无**已证实**进入切面。缺证不等于证明其绝不会采购。 |
| C6 | 竞争者同时外购核心单元 | 自有系统产品线，同时有该主体向集团外采购电化学核心部件的可核记录 | 同时标 `Direct competitor` 与 `Component procurement`；不自动否决 / 升 `High`，继续核 BDD 供货资格。 |
| C7 | 仅有通用 AOP 工程能力 | EPC 设计 Fenton / 臭氧等工段，无自有专有同域产品 | 标 `Integration overlap`，不按直接竞争者否决。 |
| C8 | 私企财务资料缺失 | 普通网页未见负面，无可靠主体级财报或困境登记覆盖 | `Financial Warning = Unknown`；不得把「未发现」写成 `No`。 |
| C9 | 近期主体级材料覆盖 | 官方财报 / 审计或可靠登记检索覆盖目标主体和时段，未见 6.1 白名单警示 | 可判 `No`，列来源、时段、主体；解释这不等于财务健康评级。 |

回归时逐例检查 `FACT / INFERENCE / UNKNOWN`、主体层级、E#、主卡与附录 B 是否一致；若改变档位，保留旧规则与新规则的判定路径供人工复核。

**本表只用场景编号，不写具体公司名。** `C1`–`C9` 对应的对照样本只保存在本机工作区（不入库），
因此**不得用本表机械套结论**，一律以当次检索到的证据为准。
