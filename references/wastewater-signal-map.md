# Wastewater Signal Map · 废水信号识别（V1.1）

> ⚠️ **本文件为骨架，只建立结构，不填入未经确认的技术判断。**
> 用途：从**文字**中识别废水相关信号。
> **本文件的输出是"识别到什么"，不是"水质参数是多少"。禁止输出任何数值区间。**

> **V1.1 新增**：第 2 节 **CSD 识别**（Customer-stated Demand，来自询盘文字）。
> 原第 2~3 节承担的是 CSD 职能；本次显式命名并与 `PWE`（公开侧，见 `lead-signals.md`）分开归属。

---

## 一、两类信号的归属（V1.1 明确）

| 信号类 | 来源 | 识别文件 | 去向 |
|---|---|---|---|
| **CSD**<br>Customer-stated Demand | **询盘文字** · 客户自述 | **本文件** | `Demand Status` 第二行 · `BDD Relevance` 输入 6 |
| **PWE**<br>Public Wastewater Evidence | 官网 · 年报 · 政府文件 · 公开案例 | `lead-signals.md` 第一节·补 | `Demand Status` 第一行 · `BDD Relevance` 输入 6 · `Current Wastewater Treatment / Technology` |

> ⚠️ **两者不得混写。** 客户在邮件里说"我们有污水站"是 CSD；官网载明"已投运 30 KLD ZLD"是 PWE。

## 二、CSD 识别（询盘文字 → 需求陈述）

从询盘文字中识别客户**明确陈述**的需求信息。

| 客户说法 | 识别结果（CSD 内容） | 类型 |
|---|---|---|
| "我们的污水站要改造" | 存在改造需求（工段待确认） | FACT（Source: 客户自述, Confidence = Low） |
| "出水 COD 不稳定，有时超标" | 存在达标压力（**非具体数值**） | FACT（Source: 客户自述） |
| "想问下你们设备多少钱" | 仅价格询问，无需求陈述 | 记入 `Commercial Risk` 观察项 |
| "我们有个项目在做" | 存在项目陈述（**需索要项目证据**） | FACT（Source: 客户自述） |
| "大概几百吨水" | 客户口径，未经检测确认 | INFERENCE（需 Reason） |

**识别规则**：
- 客户**明确陈述** → FACT（Source: 客户自述，Confidence 只能为 `Low`）
- 从描述**推断** → INFERENCE（必须写 Reason）
- 无法识别 → `UNKNOWN`

## 四、废水特征关键词 → 特征信号识别

**只做定性标注。**

> 【待填】关键词表，以及每个特征可能对应的干扰因素类型。

| 客户描述关键词 | 特征信号（定性） | 可能涉及的干扰因素类型 |
|---|---|---|
| 【待填】例：含酚 | 酚类有机物 | 【待填】 |
| 【待填】例：含络合金属 | 重金属络合物 | 【待填】 |
| 【待填】例：高盐 | 高盐体系 | 【待填】 |
| 【待填】例：有颜色 | 高色度 | 【待填】 |
| 【待填】例：有泡沫 | 表面活性剂 | 【待填】 |

**输出格式**：只能输出信号名，例如 `特征信号：含酚类有机物`。
**禁止**：输出"含酚废水通常 COD X~Y"这类数值判断。

## 五、数据提供完整度检查

用于生成 `What Is Missing`（三级优先级见 `must-ask-params.md`）。

| 需要的信息 | 客户是否提供 | 未提供则列入 |
|---|---|---|
| 需求性质（自用 / 项目 / 渠道） | | **Business** |
| 主体全称与登记信息 | | **Business** |
| 终端客户或项目业主（渠道 / 工程型） | | **Business** |
| 是否存在具体项目及阶段 | | **Project** |
| 目标工段 | | **Project** |
| 进水 COD 或目标污染物浓度 | | **Technical** |
| 特征污染物类型 | | **Technical** |
| 盐度 / 氯离子含量 | | **Technical** |
| 处理水量 m³/d | | **Technical** |
| 目标限值 / 执行标准 | | **Technical** |
| 检测报告（CMA 资质） | | Technical（视情况） |
| pH / SS / 色度 | | Technical（视情况） |

**规则**：
- 客户提供的数据**必须标注来源**：`客户自述` / `检测报告` / `客户口径未经检测确认`
- 检测报告超过 6 个月 → 标注"检测时效存疑"
- 无 CMA 资质报告 → 标注"数据不可直接用于设计"

## 六、待校准项

| # | 待填内容 | 归属 |
|---|---|---|
| 1 | 实际遇到过的行业清单与识别关键词（映射到 T1~T4 / A1~A3） | 销售 |
| 2 | 客户描述中常见的废水特征关键词 | 销售 |

| 4 | 哪些信息属于"必需"、哪些属于"视情况" | 技术 + 销售 |
| 5 | 客户常见的数据提供形式（自述 / 报告 / 表格） | 销售 |

## 七、与其他文件的职责边界

| 文件 | 负责 |
|---|---|
| **本文件** | 从**文字**识别 CSD 与特征信号（定性） |
| `lead-signals.md` | 从**外部来源**检索 PWE 与证据 |
| `evidence-policy.md` | 决定识别结果标 FACT / INFERENCE / UNKNOWN；Demand Status 定级 |
| `bdd-fit-rules.md` | 判定 Industry Fit |
| `bdd-relevance-rules.md` | 判定 BDD Relevance（消费两类废水证据） |
| `must-ask-params.md` | 三级优先级缺项清单 |

**六者不可互相替代。** 本文件不产出任何判定等级，不做技术可行性判断。
