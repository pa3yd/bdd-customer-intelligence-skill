# Lead Signals · 检索指引（V1.1）

**本文件只负责"去哪里找、找到什么算证据"。判定由 `evidence-policy.md`、`bdd-fit-rules.md`、`bdd-relevance-rules.md` 负责。**

**对应工作流位置**：SKILL.md **第 3 步 Evidence Collection**。检索产物同时服务于第 2 步 Company Verification 与第 4 步 Company Profile。

> **V1.1 新增**：第 1.5 节 **PWE 公开废水事实检索**（此前缺失，导致仅凭公司名背调时无法取得 PWE）；
> 第 2.5 节 **集团级 / 厂区级区分**（服务 Priority Site 判定）。

---

## 一、BDD 行业三件套（检索优先级最高）

**本行业真正精准的信号是这三样**，因为它们直接指向"是否存在强制治理需求"。

### 1. 环保处罚记录 ★★★

| 项 | 内容 |
|---|---|
| **证据价值** | 政府公示的处罚记录 = 独立第三方证据。是 Demand Status 升到 `Strong Signal` 的主要来源之一，也是 `Priority Site` 的首要权重 |
| **检索方式** | `"{公司名} 环保处罚"` / `"{公司名} 行政处罚 生态环境"` / `"{公司名} 超标排放"` / `"{公司名} environmental fine penalty violation"` / 当地生态环境部门公示栏目 |
| **取证要求** | FACT，**必须有 Source** |

判断要点：

| 信号 | 说明 |
|---|---|
| 近 12 个月内被处罚 | 时效内，信号有效 |
| 处罚事由涉及 COD / 氨氮 / 特征污染物超标 | 与本行业应用相关 |
| 多次被处罚 | 原有工艺长期不达标 |
| 已公开整改方案 | 项目可能已在推进 |

> **不要把处罚记录直接写成结论。** 它只是证据，等级由 `evidence-policy.md` 确定。

### 2. 环评公示 / 排污许可证 ★★★

| 项 | 内容 |
|---|---|
| **证据价值** | 项目最早的公开信号，通常比询盘早 3~12 个月；文件往往载明水量、废水种类、执行标准 |
| **检索方式** | `"{公司名} 环境影响评价"` / `"{公司名} 排污许可证"` / `"{公司名} environmental permit / EC compliance report"` / 全国排污许可证管理信息平台 |
| **取证要求** | FACT，必须附 Source |

判断要点：
- 环评写明"新建废水处理站"或"改造" → 明确设备需求
- 环评载明的废水种类、水量、标准 → **可作为客户技术数据（Source：环评公示）**，仍需注意时效
- 已过审批进入建设期 → 采购窗口

### 3. 招投标信息 ★★☆

| 项 | 内容 |
|---|---|
| **检索方式** | `"{公司名} 招标 废水"` / `"{公司名} tender effluent treatment"` / 政府采购网 / 公共资源交易中心 / 海外公共采购平台 |
| **取证要求** | FACT，必须附 Source |

判断要点：
- 已发招标公告 → 有预算、决策链已启动
- **中标方是环保工程公司 → 该工程公司可单独作为潜在客户开发**（Partner Path）
- 招标技术要求载明水量、水质、标准 → 可作为客户技术数据

### 4. 辅助信号 ★☆☆

| 信号 | 说明 |
|---|---|
| 招聘环保工程师 / 水处理操作工 / 公用工程主管（含废水处理） | 有设施在运行或即将运行；对 `Priority Site` 有加权意义 |
| 新增产线 / 扩产公告 | 废水量可能增加 |
| 集团上市 / 融资 | 合规压力上升 |
| 新闻中的技改项目 | 可能配套废水改造 |
| 官网有"环保 / 可持续"栏目并披露指标 | 重视合规；同时是 PWE 来源 |

辅助信号本身**不足以**把 Demand Status 提升到 `Strong Signal`（属间接信号 → `Potential`）。

## 一·补 · PWE 公开废水事实检索（V1.1 新增）

> **为什么新增**：5 次实跑中，仅凭公司名 + 官网做背调时无法取得"废水信号"，
> 导致 `BDD Relevance` 从定义上不可达 `High`。V1.1 起 `PWE` 单独成立即可支撑 `High`，因此必须给出检索路径。

**检索目标**：取得主体**废水设施与排放状况**的公开事实。

| 来源 | 检索方式 | 典型可得内容 |
|---|---|---|
| **官网环境 / 可持续栏目** | 直接访问 `官网/sustainability`、`/environment`、`/ehs` | ETP / ZLD / 水回用率 / 排放数据 / 环境投资 |
| **年报 · ESG · BRSR · 可持续发展报告** | `"{公司名} sustainability report / annual report water"` | 取水量、排放量、水回用、设施清单 |
| **政府许可 / 合规报告** | `"{公司名} EC compliance report effluent"` / `"{公司名} 排污许可执行报告"` | 排放限值、废水产生量、设施运行情况 |
| **公开项目案例** | `"{公司名} wastewater treatment case study"` | 现有工艺单元、改造实例 |
| **供应商 / 合作方披露** | 搜索其水处理供应商的案例页 | 设施规模与工艺（属第三方来源，Confidence 降级） |
| **招聘信息载明的设施** | `"{公司名} ETP operator / wastewater treatment job"` | 存在某类设施与运行班组 |

**取证要求**：
- 每条 PWE 均为 **FACT**（须 Source）或 **INFERENCE**（须 Reason + Confidence）
- 提取口径遵循 `current-treatment-rules.md`（只写工艺单元名，**禁止数值区间与技术参数**）
- 摘自上市公司年报的排放数据可作为 FACT 记录，但**不得用于任何技术可行性判断**

**海外主体的可用渠道**（替代中国专用渠道）：

| 地区 | 可用公开渠道 |
|---|---|
| 印度 | CPCB / 各邦 SPCB、environmentclearance.nic.in、BSE / NSE 公告、BRSR |
| 欧盟 | 各国环境署（如比利时 VMM、德国州环保局）、E-PRTR、公司年报 ESG Data book |
| 美国 | EPA ECHO、Violation Tracker、SEC 文件 |
| 通用 | 公司官网 + 年报 + 官方新闻稿 |

> ⚠️ **若某地区确实不存在公开渠道** → 输出 `UNKNOWN · no source`，**不得写成"未发现异常"**。

## 二、主体信息核实

**服务三处**：Company Verification（第 2 步）、Company Profile（第 4 步）、Customer Type / Path 与 Commercial Risk。

| 查什么 | 为什么 | 检索方式 |
|---|---|---|
| 成立时间 | 新公司需谨慎 | 企业信用公示 / 公开企业信息页 / 商业登记 |
| 注册资本 | 参考项 | 同上 |
| 员工数（口径需注明） | **最接近真实规模的数据** | 企业年报 / BRSR / 商业登记 / 官网 |
| 是否实体工厂 | 有厂址 + 有环保设施 = 真实业主 | 卫星地图、招聘信息厂址、官网 Locations |
| 经营范围 / 登记业务 | 含废水处理 / 环保工程 → 可能是 Partner | 工商信息 / 商业登记（Handelsregister 等） |
| 是否为分公司 / 子公司 | 影响决策链长度与联系角色 | 股权结构 |
| 邮箱域名 | 企业域名 vs 免费邮箱 | 域名反查 |
| 官网是否真实运营 | 空壳站信号 | 访问官网、看更新时间 |
| **采购再转售证据** | 判定 Distributor 的实质依据（V1.1 替代"参保 < 20 人"） | 产品是否源自第三方品牌 / 是否独家或授权分销 / 有无自有生产 |

**取证要求**：以上均属 FACT，必须有 Source；无法确认的写 `UNKNOWN` + 三态后缀。

### Company Verification 三态判定

| 结果 | 判据 |
|---|---|
| `Verified` | 登记全称查得到 + 存续 + 与客户自述名称一致 + 无重名歧义 |
| `Partially Verified` | 主体存在，但名称有出入 / 部分字段缺失 / 与自述地址不符 |
| `Unverified` | 查不到主体；或重名无法区分 |

**硬规则**：`Unverified` 时**不得选择最像的一家**，须列入 `What Is Missing`（Business 级）。

### 规模参考（需业务方校准）

- 员工数 < 20 人 + 无实体工厂 → 大概率是渠道型主体（**但仍需以"采购再转售"证据为准**）
- 员工数 > 200 人 + 有工厂 → 终端业主概率高

> **V1.1 修正**：不再把"参保 < 20 人"作为硬门槛——该数值在海外主体上普遍无法核实（5 次实跑中 3 次失效）。

## 二·补 · 集团级 / 厂区级区分（V1.1 新增）

**服务 `Priority Site` 判定。**

| 层级 | 记录什么 | 用途 |
|---|---|---|
| **集团级** | 站点总数、集团员工数、集团环境政策、集团排放总量、集团投资 | `Company Profile` · `BDD Relevance` ② |
| **厂区级** | 具体厂区名 / 所在地 / 工艺定位 / 该厂区的设施与合规记录 / 该厂区岗位招聘 | `Priority Site` · `What Is Missing`（Project 级）· 接触对象 |

**硬规则**：

| # | 规则 |
|---|---|
| 1 | **集团级数据不得直接写成某厂区数据。** 集团排放总量 ≠ 单个厂区排放量。 |
| 2 | 厂区级信息无法确证时，标注 `Group-level only`。 |
| 3 | 场景涉水密度高的厂区优先记录（湿法冶金、化学反应、精炼、合成）。 |
| 4 | 厂区清单至少列出：厂区名 · 国家 / 地区 · 公开可确认的定位。 |
| 5 | 若存在同名近似主体或同集团多个法律主体 → **单独列出并区分**（见第四节）。 |

## 三、检索输出的标准格式

**第 3 步只产出 Evidence，不产出判定。**

```markdown
| # | 类型 | 结论 | Source | Reason | Confidence | Decision Impact |
|---|---|---|---|---|---|---|
| E1 | FACT | 2026-03 因 COD 超标被处罚 | {公示页 URL} | — | High | High |
| E2 | FACT | 员工 320 人（BRSR） | {URL} | — | High | Medium |
| E3 | INFERENCE | 废水可能含酚类 | — | 环评载明工艺段 | Medium | High |
| E4 | UNKNOWN · searched | 环评公示（已检索未查到） | — | — | — | Low |
```

规则：
- 每条**只写一个结论**，不得合并
- 无 Source 的信息**不得标 FACT**
- 查不到写成 `UNKNOWN` + 三态，**不写"未发现异常"**
- `Decision Impact` 只影响展示优先级，不影响真实性判断

## 四、同名主体排除（必做）

**同一集团常有多家名称相近但法律主体不同的公司**，误关联会直接翻转结论。

| 步骤 | 动作 |
|---|---|
| 1 | 检索命中处罚 / 事件时，先核对该记录中的**主体全称 / 股票代码 / 注册地** |
| 2 | 与本主体的厂区清单、注册地、上市代码交叉比对 |
| 3 | 若不一致 → 按 `evidence-policy.md` 排除，并在附录记为 `UNKNOWN（排除项）` + 写明核实过程 |
| 4 | **未排除前不得计入 Demand Status 与 Commercial Risk** |

> **高危场景**：集团名称为「X + 行业词」的变体（如同一集团下的「XX 工业 / XX 制药 / XX 医药」多个法人）。

## 五、常见检索失败的处理

| 情形 | 处理 |
|---|---|
| 中小企业公开信息极稀薄 | 输出多条 `UNKNOWN · searched`，并在 `What Is Missing` 中列出建议客户提供的材料。**这是常态，不是检索失败** |
| 名称有歧义 / 重名 | 输出 `UNKNOWN`，标注"主体待确认" |
| 只有 B2B 平台信息 | 可标 FACT，但 Confidence = `Low` |
| 信息互相矛盾 | 两条都列出，标注"来源冲突"，不给结论 |
| 客户自述与公开信息冲突 | 两条都列出，优先采信公开来源，并标注冲突 |
| 该地区无公开监管渠道 | `UNKNOWN · no source`（**不得写成"未发现异常"**） |

## 六、与其他文件的职责边界

| 文件 | 负责 |
|---|---|
| **本文件** | 从外部来源**检索**证据（含 PWE） |
| `evidence-policy.md` | FACT / INFERENCE / UNKNOWN 标注；Demand Status 与 Commercial Risk / Financial Warning 定级 |
| `bdd-fit-rules.md` | 判定 Industry Fit |
| `bdd-relevance-rules.md` | 判定 BDD Relevance（消费本文件检索的 PWE 与环境证据） |
| `current-treatment-rules.md` | 现有处理方案 / 技术组合的提取口径 |
| `opportunity-type-rules.md` | Priority Site（消费本文件的厂区级检索结果） |
| `wastewater-signal-map.md` | 从文字识别客户侧信号（CSD） |

**本文件不产出任何判定等级。**
