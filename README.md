# BDD Customer Intelligence · 客户背调 Skill

> 给它一个**公司名**或**官网网址**，它帮你查清这家公司是什么来头、值不值得开发、该找谁聊。

| | |
|---|---|
| **Skill 名称** | `bdd-inquiry-analyzer` |
| **当前版本** | V1.2.1 |
| **适用业务** | BDD 电极 · 电化学氧化工业废水处理（Boromond 波乐美） |
| **适用对象** | 销售、市场、业务开发同事 |
| **一句话** | 把"这家公司能不能做"从拍脑袋变成有依据的判断 |

---

## 1. 这个 Skill 是什么

一个装在 WorkBuddy 里的 AI 助手技能。你把一家潜在客户的公司名或官网丢给它，
它会自动去查公开资料，然后给你一张**客户情报卡**。

它回答的是销售最关心的六个问题：

1. 这家公司**是做什么的**？
2. 它属于**我们的目标市场**吗？
3. 它有没有产生**我们能处理的废水**？
4. 它现在**已经在用什么处理方案**？
5. 这个客户**值不值得投入**？下一步该干什么？
6. 该联系**哪个部门、哪个岗位**？

**它不是搜索引擎。** 它把散落在官网、年报、政府公示、招投标、环保许可里的信息
**汇总成一张可以直接拿去看的卡**，并且每条结论都标注来源。

## 2. 适合什么场景

### ✅ 用它

| 场景 | 举例 |
|---|---|
| 拿到一个陌生公司，想快速摸清底细 | 展会名片、客户转介绍、线上询盘 |
| 判断这家公司算不算我们的目标客户 | 化工、制药、锂电、印染、电镀、半导体…… |
| 手上有一批名单，想先筛一遍再投入 | 潜在客户长名单初筛 |
| 准备拜访或发邮件，想提前做功课 | 了解对方厂区、业务、环保现状 |
| 判断该走终端客户还是渠道 / 工程合作路线 | End-user 还是 EPC / 集成商 / 分销商 |
| 想找对的人 | 该联系 EHS 负责人、环保主管还是技术总工 |

### ❌ 别用它

| 不适用 | 说明 |
|---|---|
| 要技术方案 / 设备选型 / 工艺参数 | 这属于工程师的工作，Skill 按设计**不输出** |
| 要报价、核算、商务条款 | 明确排除在外 |
| 要写邮件、话术、跟进节奏 | 明确排除在外 |
| 纯工商信息查询、找电话邮箱 | 这不是它的定位 |
| 消费品外贸询盘（泳具、体育用品等） | 用另一个 Skill：`ai-inquiry-analysis` |

> **一条重要边界**：这个 Skill 只做**情报**，不做**承诺**。
> 它不会告诉你"这单能成"、也不会给你具体工艺方案 —— 那些留着找技术同事。

## 3. 如何安装

### 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 |
| WorkBuddy | 已安装并登录（Skill 的运行环境） |
| Python | 3.10 以上（生成 PDF 需要，WorkBuddy 自带） |
| 浏览器 | 装了 Google Chrome 或 Microsoft Edge 即可 |

### 安装步骤

Skill 必须放在 WorkBuddy 的 skills 目录里才会生效：
`C:\Users\<你的用户名>\.workbuddy\skills\`

**方式一 · 用 Git（推荐，方便以后更新）**

打开 PowerShell：

```powershell
cd $env:USERPROFILE\.workbuddy\skills
git clone <仓库地址> bdd-inquiry-analyzer
```

**方式二 · 手动下载（不用装 Git）**

1. 打开本仓库页面 → 右上角绿色 **Code** → **Download ZIP**
2. 解压后会得到一个类似 `bdd-customer-intelligence-skill-main` 的文件夹
3. **把文件夹重命名为 `bdd-inquiry-analyzer`**（这一步不能省，名字必须一致）
4. 把它整体移动到 `C:\Users\<你的用户名>\.workbuddy\skills\`

### 装完检查

确认这个路径存在且 SKILL.md 在里面：

```
C:\Users\<你的用户名>\.workbuddy\skills\bdd-inquiry-analyzer\SKILL.md
```

然后 **重启 WorkBuddy**（它只在启动时扫描 skills 目录，不重启不生效）。

## 4. 如何调用

**不需要背任何命令，用大白话说就行。**

只要提到一个公司名或网址，并表达"想了解这家公司"的意思，它就会自动启动完整流程。

### 可以直接这样说

```
背调 <公司全称>，<官网域名>
```

```
分析客户：<公司全称>，<官网域名>
```

```
<公司全称> 是否值得作为 BDD 客户开发？
```

```
帮我看看 <官网域名>
```

### 其他同义说法

- 查一下这家公司
- 这家公司什么来头
- 判断一下是不是 BDD 客户
- 这家公司该不该跟

### 输入门槛很低

| 你手上有什么 | 能不能用 |
|---|---|
| 公司全称 + 官网 | ✅ 效果最好 |
| 只有官网网址 | ✅ 可以，它会先做主体识别 |
| 只有公司名 | ✅ 可以 |
| 只有一份询盘邮件 / 名片 / 聊天记录 | ✅ 可以 |
| 信息很少 | ✅ 可以，但会如实标注"未知"，**不会硬编** |

> **不用告诉它版本号、字段清单、输出格式。** 这些它自己知道。

## 5. 输出什么

每次执行会给你**两个文件**：

| 文件 | 用途 |
|---|---|
| `{公司简称}_BDD_Intelligence_{日期}.md` | 完整版，含全部证据与审计信息 |
| `{公司简称}_BDD_Intelligence_{日期}.pdf` | **三页业务版**，可以直接打印或转发 |

### PDF 三页结构

| 页 | 内容 | 给谁看 |
|---|---|---|
| **Page 1** | 客户快照 —— 一页看清"是谁、有没有机会、下一步" | 你自己 / 主管 |
| **Page 2** | 开发情报 —— 5 张卡：为什么要做 / 现状 / 优先厂区 / 找谁 / 待核实 | 拜访前准备 |
| **Page 3** | 关键依据 —— 6~8 条关键证据 + 来源 | 需要追问时 |

### Page 1 的 13 个字段

**WHO · 客户是谁**
公司 · 国家 · 主营业务 · 客户类型与路线

**WHY · 为什么值得看**
行业匹配 · BDD 机会（含机会类型）· 需求状态

**WHERE / WHO · 从哪里切入**
现有废水处理或技术组合 · 优先厂区 · 该联系谁

**ACTION · 现在怎么办**
还缺什么信息 · 下一步做什么 · **销售结论**

### 颜色一眼看懂

| 颜色 | 含义 |
|---|---|
| 🟢 绿 | 已确认 / 正面 / 高 |
| 🟡 黄 | 有可能 / 待验证 |
| 🔴 红 | 风险 / 冲突 |
| ⚪ 灰 | 未知（查了但没找到，或还没查） |
| 🔵 蓝 | 中性 / 规划中 |

### 销售结论只有五种

`建议开发` · `建议先验证` · `建议观察` · `暂不投入` · `信息不足，暂缓判断`

> ⚪ 灰色「未知」**不等于**「没有」。
> 它意味着"这次没查到"。信息不足时它宁可写未知，也不会猜。

## 7. 数据安全注意事项

这个 Skill 处理的是**客户情报**，请务必注意以下几点。

### 使用中

| 事项 | 说明 |
|---|---|
| **只用公开信息** | 官网、年报、政府公示、招投标、环保许可、官方媒体等公开渠道 |
| **不输出技术承诺** | 按设计不输出工艺方案、设备选型、技术参数、达标承诺 |
| **不输出商务信息** | 不输出报价、金额、合同条款 |
| **人名有严格限制** | 只输出**岗位角色**；人名仅可来自官网 / 政府公示 / 招投标 / 上市公告 / 官方媒体，**第三方人才库与数据聚合站的人名一律不用** |
| **不编造** | 查不到就写 `Unknown`，并标注是"查了没有"还是"没查" |
| **每条结论可溯源** | 事实类结论必须附来源（Source）；推断类必须附理由与置信度 |

### 使用后

| 事项 | 说明 |
|---|---|
| **产物含客户信息** | 生成的 `.md` 与 `.pdf` 含客户名称、厂区、联系人岗位等，**属公司业务资料** |
| **不要外传** | 不要发到公开渠道、个人社交账号、外部群组 |
| **不要提交到公开仓库** | 你的背调结果不要 push 到任何公开代码仓库 |
| **注意合规** | 对外使用前，确认符合公司数据管理与客户信息安全要求 |

### 一句话原则

> **公开信息进、判断依据出。**
> Skill 只读公开资料，只产出有来源的判断；不碰你的客户名单，也不碰内部数据。

## 附：常见问题

**装好了但没反应？**

1. 确认路径是 `...\.workbuddy\skills\bdd-inquiry-analyzer\SKILL.md`
2. **重启 WorkBuddy**（最常见的原因）
3. 确认没有和 `ai-inquiry-analysis`（消费品外贸专用）搞混

**生成的 PDF 打不开 / 没生成？**

检查是否装了 Chrome 或 Edge。PDF 由浏览器渲染，两个都没有就生成不了。

**它说"未知"的太多了？**

正常。你给的输入越具体（公司全称 + 官网），结果越完整。
如果手上还有询盘邮件、名片、聊天记录，一起发给它，`需求状态` 那一栏会更准。

**它会不会自己编？**

不会。找不到就写未知。这是设计原则 —— 宁可说不知道，也不给假信息。
